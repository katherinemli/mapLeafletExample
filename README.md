# Leaflet Map Example (Vue)

**[Français](#français) · [English](#english)**

---

## Français

Carte interactive en Vue 2 qui charge des points d'intérêt depuis une API REST et les affiche sous forme de marqueurs personnalisés avec infobulles et fenêtres contextuelles.

### Points forts
- Carte **vue2-leaflet** avec icônes de marqueurs personnalisées, infobulles au survol et fenêtres contextuelles au clic
- Données récupérées avec Axios depuis une API en Go
- Communication par événements enfant → parent entre un panneau d'outils de configuration et la carte
- Déployé sur Netlify

### Technologies
Vue 2 · Leaflet / vue2-leaflet · Axios · Netlify

### Exécution locale
```bash
npm install
npm run serve
```

---

## English

Interactive map in Vue 2 that loads points of interest from a REST API and renders them as custom markers with tooltips and popups.

### Highlights
- **vue2-leaflet** map with custom marker icons, hover tooltips and click popups
- Data fetched with Axios from a Go API
- Child-to-parent event communication between a config tool panel and the map
- Deployed on Netlify

### Stack
Vue 2 · Leaflet / vue2-leaflet · Axios · Netlify

### Run locally
```bash
npm install
npm run serve
```
